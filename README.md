# Taller de Dibujo

App para que una niña de 7 años aprenda a dibujar paso a paso, en tres unidades:

1. **Dibujar por partes**: gato, casa y pez, armados con círculos, óvalos y triángulos.
2. **Luz y sombra**: un laboratorio donde se arrastra el sol y se ven el brillo, la sombra propia y la sombra en el piso; luego una pelota y un cubo sombreados por zonas (claro, medio y oscuro).
3. **Perspectiva**: un laboratorio donde se mueve el punto de fuga; luego un camino con árboles y una caja en perspectiva de un punto.
4. **Construir con bloques**: se elige una forma (cuadrado, rectángulo, triángulo, semicírculo, círculo, arco, trapecio, estrella, óvalo, rombo, hexágono, corazón, nube), se pinta con el dedo o con diseños (ladrillos, tejas, madera, ventanas...) y se guarda en la caja. Después se construye una casa, un edificio, un carro, un castillo, un tren, un barco, un cohete, un robot, un árbol o un jardín: las piezas encajan solas sobre siluetas punteadas. También hay construcción libre con luz y sombra.

Cada lección tiene un modo **Calcar** (línea punteada para seguir) y un modo **Copiar** (dibujar mirando el modelo). También incluye la herramienta **Sombra**, que se oscurece con cada pasada como un lápiz de grafito, una voz que lee los pasos, una galería y dibujo libre.

## Cómo usarla

Abre `index.html` en el navegador de una tablet o un computador. No necesita servidor ni internet, salvo para cargar las fuentes. Los dibujos y las estrellas se guardan solo en ese navegador.
